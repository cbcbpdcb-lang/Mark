# EchoRank — 直销品牌官网口径体检

> 用户在购买或加入之前会问 AI：“这是不是传销？”“精油能治病吗？”“买了能退吗？”EchoRank 把 DeepSeek、Kimi、千问、豆包等模型的回答和品牌官网口径逐条比对，找出哪里说反了、哪里说过期了、哪里在替品牌夸大疗效，每一条都附官网原文、AI 原句、出现次数和置信区间，最后生成一份《官网口径体检报告》。
>
> 只做“发现问题”：不替品牌写或发布内容，不删帖，不压制负面信息。

## 它和现有 GEO 工具的区别

现有工具（腾讯 AnswerBit、新榜智汇、AIDSO 等）回答的是“品牌有没有被提到、排第几”。EchoRank 在此之上多做三件事：

1. **以品牌确认、带生效期的事实底账为裁判**，而不是全网共识。全网共识会被软文投毒（2026 年 3·15 曝光案例），品牌底账不会。
2. **每个错误分五类并追溯到具体页面**：能力遗漏、过期事实、无依据能力、错误归属、定位偏差；被引用的页面再判断是否疑似软文或过期来源，每个判断都列出理由。
3. **公开测量本身的可信度**：每个比例都带 Wilson 95% 区间、可信度等级、重复一致性和“规则 vs 人工复核”一致率。

## 工作流

```
粘贴官网文字 → 模型抽取候选事实 → 程序核对原文引语 → 人工逐条确认 → 发布事实 vN
        ↓
冻结问题集 → 采集（API 脚本 / App 人工导入）→ 确定性规则评测 → 错误溯源 → 可信度等级
        ↓
认知差异 → 内容实验（基线、干预、等待期、可比性检查）→ 复测
```

## 指标定义

- **可验证认知覆盖率**（北极星）：提到产品、至少说对一项已确认事实、且没有任何错误的有效回答 / 有效回答。
- **可信度等级**：Wilson 95% 区间半宽 ≤ 10 个百分点为“结论可用”，10–25 为“仅作方向”，其余为“不足以下结论”；规则与人工复核一致率低于 80% 时降一级。
- **错误溯源强度**：同句引用 > 同回答引用 > 无法溯源。
- **疑似软文**：三条规则命中至少两条才标记，每条理由可见，可人工覆盖。
- **客户确认**：事实底账每条口径可记录“客户确认人、确认日期”；报告按条标注“客户已确认 / 未经客户确认”，并附口径确认状态表。未经客户确认的口径，发现仅供参考。

## 本地运行

1. 双击 `index.html` 即可使用全部评测功能（数据保存在浏览器）。
2. 采集：复制 `.env.example` 为 `.env`，填入密钥后 `source .env`，运行 `python3 collect.py --dry-run`，再 `python3 collect.py --repeats 2`。
3. 把生成的 `runs_*.json` 在页面「数据导入」导入。

## 公开版

仓库里的 `index.html` 保留真实品牌名，作为内部工作数据。公开网站上传的是匿名版：

```bash
python3 build_public.py        # 生成 dist/index.html，源代码里不再有真实品牌名、官网链接、证照号、电话
python3 build_public.py --check   # 只检查不写文件
```

替换名单在 `index.html` 的 `DIRECT_A_PUBLIC` 一行。公开版同时把 `PUBLIC_BUILD` 置为 true，不显示「分析一个产品」等自助入口（产品定位是 to B 服务交付，采集由服务方完成，客户只看报告）。生成后先在浏览器里打开 `dist/index.html` 看一遍，再上传。页面运行时还有一层匿名（预设的 `anonymize`），本地打开显示真实版，侧栏可以勾选“按公开版预览”。
